REARMED 0.6.1-beta - an arena mod for Quake III Arena
=====================================================

Every gun gets a second trigger. REARMED adds alt-fire to all weapons, modern
movement (double jump, wall jump, wall run, dash, slide, ground pound, offhand
grapple, zip line), the Team Arena weapons, headshots, gore and physics, random
events, perks, killstreaks, medals, a style meter, a kill cam, bots that use all of
it, and DESCENT: a roguelike run through four acts of floors with bosses, weapon
levels and evolutions, chests, skill trees and characters to unlock.
It also fixes widescreen (Hor+ field of view, ultrawide HUD) and adds modern effects.

NEW IN 0.6.1
Fairer bosses (smaller health pools, no one-shots, a little slower), boss floors
on small maps, a boss locator (a marker through walls, an arrow when off screen),
and four vault modes: gem rain, shooting gallery, rush and sky vault.

NEW IN 0.6
Smarter bots in every mode: they flank, dodge rockets and rails, rocket-jump,
time the big items, hunt you by sound, learn your favourite gun, and grab the
weapon you drop (kill the thief to take it back). Taunts and grudges.
Hit feel: flinch and stagger, heads and limbs blown off, crawling, panic, wall
splats, armour that cracks. Switches on the F10 BOTS and HITS tabs.
DESCENT: nine enemy types, eight elite affixes and champion packs, a nemesis that
levels up when it kills you, bots that remember you across runs, a Nemesis Hall,
a Bestiary, timed 1v1 boss fights (5:00, unlimited deaths), boss practice and
rematches with harder modifiers, and a Daily Challenge with a personal best table.

REQUIREMENTS
  - Quake III Arena (Steam or GOG). Team Arena, which comes with both, is used for
    the nailgun, chaingun and prox launcher models if you have it.
  - Windows 10/11, a GPU with OpenGL 3.

INSTALL
  1. Unzip this folder anywhere.
  2. Run "Play REARMED.bat". The first start finds your Quake III install and
     copies the Team Arena weapon files from your own copy into REARMED's folder.
  3. Press F10 in game (or Main menu > REARMED) for the settings: every feature
     can be switched off.

CONTROLS (new; rebind them all in Setup > Controls)
  Right mouse   alt-fire (hold to charge)     Q / Shift   dash
  E (hold)      offhand grapple                Z           zip line (aim at a wall)
  C while running: slide        C in the air: ground pound
  R (hold)      weapon wheel, tap for the last weapon
  F / G / V     nailgun / prox launcher / chaingun
  F10           REARMED settings
  Jump in the air: double jump, or wall jump next to a wall.
  Hold forward along a wall at speed: wall run.

GAME MODES
  Normal, Gun Game, Juggernaut, Instagib, One in the Chamber (F10 > RULES).
  DESCENT: Main menu > Single Player > DESCENT (or type "descent" in the console).
  F10 > RULES > Frag target x2 / x3 makes every arena need more frags.

PLAYING 1v1 (two PCs, each with this same REARMED folder and its own Quake III)
  Host: run "Host 1v1.bat". It starts a duel server and joins it.
  Guest: run "Join 1v1.bat" and type the host's address.
  The address:
    - Easiest: both install Tailscale (free, tailscale.com), sign in, and use the
      host's Tailscale address (100.x.y.z). No router changes needed.
    - Or on the same home network: the host's local IP (ipconfig, e.g. 192.168.1.20).
    - Or over the internet: forward UDP 27960 on the host's router to the host PC
      and use the host's public IP.
    - Windows may ask the host to allow ioq3ded.exe through the firewall: allow it.
  Rules and maps for the duel are in home\rearmed\server_duel.cfg.
  Both players must use the same REARMED version (the server checks the files).
  DESCENT is single player only.

HOSTING A BIGGER SERVER
  Edit home\rearmed\server.cfg, run "Start Server.bat" and open UDP 27960.
  Every player needs REARMED and their own copy of Quake III Arena.
